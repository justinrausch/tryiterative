# 10x Landing Page

A modern, minimalist landing page inspired by 10x.app.

## Features

- Clean, modern design with dark theme
- Responsive layout for all devices
- Smooth animations and transitions
- Navigation with CAREERS, ABOUT, TEAM links
- Location indicator (SOHO, NYC)
- Hero section with gradient text effect

## Getting Started

Simply open `index.html` in your web browser to view the landing page.

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - Interactive JavaScript effects

## Customization

You can easily customize:
- Colors in the `:root` CSS variables
- Typography by changing the font imports
- Content in the HTML file
- Animations in the CSS and JavaScript files
